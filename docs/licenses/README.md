# Licences shipped with JawnOS

These are the full texts the notices in `docs/THIRD-PARTY.md` refer to.

- `runtime/` — copied into every `jawnrt-*.zip` under `licenses/` by
  `scripts/runtime_zip.pl`: the Termux-package licences, the source offer, and
  the notices for the Android runtime.
- `OFL-1.1.txt` — the SIL Open Font License, used by Noto Sans and Montserrat.
- `TFT_eSPI-FreeBSD.txt` — the licence for the three TFT_eSPI smooth fonts in
  `jt/` (`Final_Frontier_28`, `Latin_Hiragana_24`, `Unicode_Test_72`).

The firmware carries its own copies next to the font headers
(`jt/OFL-NotoSans.txt`, `jt/TFT_eSPI-LICENSE.txt`, `jw/OFL-Montserrat.txt`) so a
sketch directory is self-contained.
